# Архитектура страницы книги

`main.js` — composition root: только соединяет независимые части страницы.

- `audiobook-tracks.js` — единственное место, куда добавляются главы и ссылки.
- `audio-source-resolver.js` — заменяемые адаптеры источников; сейчас подключён Google Drive.
- `audiobook-player.js` — логика плейлиста и интерфейса, не зависящая от конкретного хостинга.
- `page-config.js` — ссылки и статическая конфигурация страницы.
- `page-links.js` — инициализация ссылок, обложки и года.
- `thoughts.js` — декоративная фоновая анимация.

Чтобы подключить аудиокнигу, достаточно заполнить массив `AUDIOBOOK_TRACKS`.
Остальные модули менять не нужно.
