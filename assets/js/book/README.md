# Модули страницы книги

`main.js` только соединяет независимые части страницы:

- `pdf-reader.js` — состояние постраничной читалки, навигация, клавиатура, свайпы и адаптация размера;
- `pdfjs-adapter.js` — изолированное подключение PDF.js и отрисовка страниц в `canvas`;
- `audiobook-tracks.js` — единственное место для глав и ссылок на аудио;
- `audio-source-resolver.js` — адаптеры источников, включая Google Drive;
- `audiobook-player.js` — плейлист, управление, перемотка, скорость и автопереход;
- `thoughts.js` — необязательная фоновая анимация.

Общие ссылки сайта, включая путь к PDF, находятся в `../site/site-config.js`, а их инициализация — в `../site/site-shell.js`. Чтобы заменить файл книги, достаточно изменить `bookPdf`: читалка и кнопки скачивания используют одно значение.
